# 🐢 천천히 키오스크

실수해도 괜찮은 키오스크 연습장 — 어르신·디지털 약자를 위한 미션형 연습 게임

2026 한신 AI·SW 페스티벌 AX 라이프케어 챌린지 자유공모 · 팀 **디지털 짝꿍** (윤정빈, 안해솔)

## 실행
- 배포 페이지: GitHub Pages 주소(저장소 Settings → Pages에서 확인)
- 로컬: `index.html`을 브라우저로 열면 됩니다. 서버나 설치가 필요 없습니다.

## 기능
- 키오스크 3종: 패스트푸드 주문, 병원 접수, 무인민원발급기(주민등록표 등본)
- 단계 3개: 연습(다음 버튼이 반짝임) → 도전(12초 머뭇거림·연속 2회 실수 시 도움) → 실전(권유 팝업 포함)
- 음성 안내, 큰 글씨, 미션 체크리스트
- 결과 리포트: 걸린 시간, 다시 찾은 횟수, 도움 횟수, 어려웠던 단계, 다음 단계 추천
- 기록은 사용하는 기기의 브라우저에만 저장됩니다(서버 전송 없음).

## 장면 바로 열기 (시연·캡처용)
주소 뒤에 붙입니다. 예: `index.html#s=burger&l=3&k=6&mute=1`

| 값 | 뜻 |
|---|---|
| `s` | `burger` · `hospital` · `civil` |
| `l` | 단계 1~3 |
| `k` | 자동으로 진행할 단계 수 (`99`면 결과 화면) |
| `m=1` | 중간에 실수 2번을 넣음 |
| `mute=1` | 음성 끔 · `big=1` 큰 글씨 |

## 참고
- 매장·병원·발급기는 모두 가상입니다. 실제 상표나 로고는 쓰지 않았습니다.
- 화면 흐름은 롯데리아 공식 키오스크 체험 페이지(2026.7)와 맥도날드 키오스크 관련 보도(2025.10)를 참고했습니다.
- 주민등록번호와 휴대폰 번호는 연습용 가짜 번호입니다.
